## ADDED Requirements

### Requirement: Чтение истории тренировок
Бот SHALL уметь выбирать сохранённые тренировки конкретного пользователя, при необходимости — за период времени (по `performed_at`), отсортированными от более поздних к более ранним.

#### Scenario: Выборка всех тренировок пользователя
- **WHEN** бот запрашивает историю тренировок пользователя
- **THEN** возвращаются только записи этого пользователя, без вымышленных или чужих

#### Scenario: Выборка за период
- **WHEN** запрашивается история за определённый период (например, последние 7 дней)
- **THEN** возвращаются только тренировки из этого периода

### Requirement: Фоновая подача данных в ответ
При формировании ответа пользователю бот SHALL включать в вызов LLM компактную сводку последних тренировок этого пользователя, чтобы бот мог естественно ссылаться на факты (регулярность, прогресс) в своём ответе.

#### Scenario: Ответ с историей
- **WHEN** у пользователя есть сохранённые тренировки и бот формирует ответ на его сообщение
- **THEN** в вызов LLM попадает сводка последних тренировок пользователя

#### Scenario: История пуста
- **WHEN** у пользователя нет сохранённых тренировок
- **THEN** в вызов LLM не передаются данные о тренировках (или передаётся отметка, что их нет), бот отвечает без ссылок на несуществующие факты

### Requirement: Отчёт о тренировках по запросу
Когда пользователь просит показать историю тренировок (например, «покажи тренировки за неделю»), бот SHALL распознать запрос, выбрать тренировки за указанный период и ответить в своём характере на основе только этих данных. Если данных за период нет, бот SHALL честно сообщить об этом, не выдумывая историю.

#### Scenario: Есть тренировки за период
- **WHEN** пользователь просит показать тренировки за период, и такие записи есть
- **THEN** бот отвечает списком/сводкой реальных тренировок из этого периода

#### Scenario: Нет тренировок за период
- **WHEN** пользователь просит показать тренировки за период, но записей нет
- **THEN** бот сообщает, что тренировок за этот период нет, и не выдумывает их

#### Scenario: Период не назван
- **WHEN** пользователь просит показать тренировки без указания периода
- **THEN** бот выбирает разумный период по умолчанию и отвечает по данным этого периода
